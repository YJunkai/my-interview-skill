## 🎯 项目简介

LLM Interview Master 是一款基于 AI Agent 的模拟面试系统，专为准备互联网大厂大模型（LLM）岗位面试的应届生设计。

### 核心功能

- ✅ **深度项目追问**：采用 STAR + 5层追问法，真实还原面试官思维
- ✅ **LLM知识图谱**：涵盖 Attention、Transformer、RLHF、LoRA 等核心考点
- ✅ **技术面+HR面**：完整的面试流程模拟，含反馈报告
- ✅ **智能评分系统**：多维度评估，给出针对性改进建议
- ✅ **高频题库**：技术问题 + HR问题 200+ 道
- 🆕 **数据/训练全链路**：数据构建/清洗、SFT 实战、RL/DPO 对齐、OPD 蒸馏（DeepSeek-R1 风格）

## 🚀 快速开始

### 前置要求

- Cursor IDE (已安装 Agent 能力)
- GPT-4 / Claude-3 / 其他兼容的大模型 API

### 使用方式

在 Cursor 中加载此 Skill，然后启动面试：

```
你: 开始模拟面试
AI:  请提供你的简历和目标岗位信息
你:  [粘贴简历信息]
```

## 🎓 面试模块

### 技术面（60-90分钟）

#### 1. 自我介绍（2-3分钟）
```
结构化表达，突出技术亮点，留白引导追问
```

#### 2. 项目深挖（30-40分钟）
```
采用 STAR + 5层追问法：
├── 第1层：任务定义（What）
├── 第2层：技术方案（How）
├── 第3层：难点突破（Why this）
├── 第4层：量化结果（Result）
└── 第5层：深度拓展（Why not better）
```

#### 3. LLM基础知识（20-30分钟）
```
根据简历背景选择考察方向：
├── Attention机制
├── 预训练与微调
├── 推理优化
└── RAG/Agent
```

#### 4. 编程题（20-30分钟）
```
LeetCode 中等难度：
├── 数据结构（链表、树）
├── 动态规划（背包、编辑距离）
└── 系统设计（LRU、线程池）
```

### HR面（30-45分钟）

| 环节 | 内容 | 时长 |
|------|------|------|
| 自我介绍 | 简短版 | 2min |
| 经历核实 | 简历真实性确认 | 10min |
| 动机挖掘 | Why this company/role | 10min |
| 职业规划 | 长期发展路径 | 8min |
| 薪资谈判 | 期望与策略 | 5min |
| 反问环节 | 候选人提问 | 5min |

## 💡 使用技巧

### 1. 单次面试
```
用户：开始模拟面试
AI：询问基本信息 → 启动技术面/HR面 → 输出反馈报告
```

### 2. 系列训练
```
用户：我想针对字节跳动面试做3次训练
AI：第1次（技术面基础）→ 第2次（项目深挖强化）→ 第3次（模拟真实面试）
```

### 3. 单项突破
```
用户：我想练习项目深挖
AI：针对简历中的每个项目进行5层追问深挖

用户：我想练习RLHF相关的技术问题
AI：提供RLHF相关的深度问题和回答指导
```
